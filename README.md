# Mithila Web Labs — Website

Company website for **Mithila Web Labs**: AI-powered business applications and digital products.

Next.js 16 · TypeScript · Tailwind CSS v4 · shadcn/ui · (Supabase, Gemini AI in later phases)

## Quick start
```bash
npm install
cp .env.example .env.local
npm run dev
```
